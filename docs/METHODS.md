# 网络算法

## 状态图

节点代表完整表面状态：有序 C1 位点组合、单个 C2 中间体或带副产物的状态。每条有向边代表一个反应通道，保留多重边。根据用户给出的自由能和规则生成图，不通过模型计算结构或能量。

## 瓶颈路径

对于路径 P 的原始边权 w：

\[
D_{minimax}(s,t)=\min_{P:s\to t}\max_{e\in P}w_e,\qquad
D_{maximin}(s,t)=\max_{P:s\to t}\min_{e\in P}w_e.
\]

使用带优先队列的瓶颈 Dijkstra。minimax 的松弛为 min(old,max(current,w))，maximin 为 max(old,min(current,w))。有限负权可直接处理，不平移、不截断。保存前驱反应，返回实际路径并保留平行边身份。空路径的瓶颈未定义，以 null 返回；不可达结果单独标记。

best_path 保留化学筛选接口：thermodynamic 使用 max(0,ΔG)，kinetic 使用明确提供的 Ea；可选择最小化最大代价或非负代价之和。热力学瓶颈不等于动力学速率决定步骤。原始带符号权重的 minimax 与截断代价的热力学描述符分别提供，避免掩盖全负权路径之间的差别。

## 可达性与计数

剪枝取从源可达和能够到达目标的节点交集，可按边代价阈值进一步筛选。多目标时保留通向任意指定目标的有效子图。

DAG 通过拓扑序进行前向/后向动态规划，以 Python 任意精度整数计数。节点出现次数为 forward(node)×backward(node)，平行通道计作不同路径。

有环图枚举简单路径，按最大边数、路径数及节点展开数限制工作量。发生截断时 exact=false，并报告触发的限制。到达目标后立即终止该路径。

## CO2RR 能量与 CHE

对 C_c H_h O_o，相对于 CO2/H2O 的还原电子数为 n_e=4c+h−2o。状态形成自由能按如下关系修正：

\[
G(U_{SHE},pH)=G^0+n_e[U_{SHE}+k_BT\ln(10)pH],\qquad
G(U_{RHE})=G^0+n_e U_{RHE}.
\]

eV/V/电子数约定下 e 的数值为 1；更负电位使还原后的状态更稳定。RHE 不再次叠加 pH 项。每条规则检查 C 守恒，按氧损失量配平水，再由氢变化配平 H+/e-。ΔG 由端点之差得到。该规则不代替恒电势、显式溶剂或电场计算。

## Markov 分析

可选 kinetics 模块用输入活化自由能构建一阶构型级 CTMC：k_ij=νexp(−Ea/kBT)，非对角 Q_ij=k_ij，Q_ii=−Σk_ij。提供产物吸收概率、陷阱概率、稳态和连续时间传播。跳跃概率按行 log-sum-exp 计算，避免大能垒下直接指数下溢。

反向边可共享同一过渡态，使用 Ea_reverse=Ea_forward−ΔG，以保持一致条件下的详细平衡。缺失能垒时不使用 ΔG 伪装成速率；稳态不唯一或方程病态时明确报错。这是一阶状态模型，不自动预测覆盖度、电流或法拉第效率。
