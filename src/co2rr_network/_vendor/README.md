# FAIR-Chem 本地源码

`fairchem/` 来自用户放入本工作区的历史修改版源码，不来自在线下载或 PyPI 安装。

源码原有的模型和数值实现保留。为放入私有命名空间，仅将内部 Python 模块引用改为 `co2rr_network._vendor.fairchem`，并使注册器的动态模块发现使用同一前缀；原发行包版本查询仍保留其原含义。

这份实现随包保留，但不由网络核心导入，不向本包注入它的训练、结构优化、过渡态命令或运行依赖。调用其具体模型时，应使用该历史实现自身兼容的计算环境。

主许可证原文位于 `fairchem/LICENSE`，原位置 `fairchem/core/LICENSE.md` 及子模块的许可证同时保留。文件中的原作者版权头不修改。
